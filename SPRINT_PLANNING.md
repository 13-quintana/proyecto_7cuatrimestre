## 4. Acuerdos del equipo

### Definition of Ready (DoR)

Una historia está lista para comenzar cuando:

- Tiene una descripción clara de lo que necesita el usuario.
- Cuenta con criterios de aceptación escritos en formato Gherkin.
- El equipo revisó y aceptó su estimación.
- Se identificaron las dependencias necesarias para trabajarla.

### Definition of Done (DoD)

Una historia se considera terminada cuando:

- La funcionalidad cumple con sus criterios de aceptación.
- El código fue revisado por otra integrante mediante un Pull Request.
- Se realizaron las pruebas correspondientes.
- Los cambios fueron integrados a la rama principal después de su revisión.
