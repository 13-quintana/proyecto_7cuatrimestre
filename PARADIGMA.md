## 1. MÉTODOS (Técnicas Sistemáticas de Desarrollo)

- **Modelo de Proceso:** Desarrollo Incremental / Ágil, considerando las prácticas propuestas por Sommerville.

- **Técnicas de Análisis y Especificación:** Historias de Usuario y documentación de los requerimientos del proyecto.

- **Técnicas de Validación:** Pruebas Unitarias y revisiones e inspecciones entre pares.

## 2. HERRAMIENTAS (Soporte Automatizado CASE y Entorno de Desarrollo)

- **Entorno Integrado (IDE):** Visual Studio Code.

- **Control de Versiones y SCM:** Git CLI local y GitHub Remote Repository.

- **Analizador Estático de Código (Linter):** Flake8 / Pylint para Python.

- **Gestión de Tareas:** Tablero Kanban en GitHub Projects.

## 3. PROCEDIMIENTOS (Estructura y Normativa Organizacional)

- **Formato de Commits:** Se utilizará una convención imperativa utilizando prefijos como `feat:`, `fix:`, `docs:`, `style:` y `refactor:`.

- **Estrategia de Ramas (Branching):** Se prohíbe realizar push directo a `main`. Todo cambio deberá realizarse mediante una rama `feature/*` y posteriormente integrarse mediante Pull Request.

- **Política de Code Review:** Todo Pull Request deberá contar con la revisión y aprobación escrita de al menos un integrante del equipo antes de realizar el Merge.
